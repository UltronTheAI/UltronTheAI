# Embedded asset licenses

- Inter and JetBrains Mono are embedded from the local Next.js build output.
- The portrait and pointing character are the supplied PNG assets, embedded as data URIs. `right_pointing-cropped.png` is a lossless alpha-preserving trim of the supplied pointing asset, removing only transparent margins for layout framing.
- SVGs contain no scripts, foreignObject elements, external images, external fonts, or network requests.
